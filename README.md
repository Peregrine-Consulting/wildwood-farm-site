# Wildwood Farm Modern Website Concept

Static concept site for Dr. Michael Hinkley and Recovery at Wildwood Farm.

Open `index.html` directly in a browser, or serve the folder with any static server.

## Direction

- Clinical editorial farm aesthetic
- Queer-normative recovery positioning
- Dr. Hinkley visible as the primary trust builder
- Clear admissions path, cost transparency, financing placeholder, and content hub
- Project-bound generated hero image saved at `assets/wildwood-hero.png`
